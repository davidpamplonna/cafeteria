# ☕ Code Café

Este projeto é uma landing page responsiva para uma cafeteria fictícia, desenvolvida como parte de uma aula prática do curso **DevClub**. O objetivo foi aplicar conceitos fundamentais de **HTML, CSS e JavaScript** na criação de uma interface moderna e funcional.

## 🔗 Acesse o Projeto

👉 [Clique aqui para acessar](https://codecafe-david-pamplona-projects.vercel.app/)

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

## 📱 Funcionalidades

- Layout responsivo para diferentes tamanhos de tela
- Navegação com rolagem suave entre seções
- Seções: Sobre Nós, Menu, Avaliações e Endereço
- Botões com chamadas para ação (CTA)
- Design moderno com imagens e ícones

## 🎯 Objetivos de Aprendizado

- Praticar estruturação de páginas com HTML semântico
- Aplicar estilos e responsividade com CSS
- Implementar interações básicas com JavaScript
